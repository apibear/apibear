# Security Policy

`apibear` handles API credentials passed via `--header`, so we take reports seriously.

## Reporting a vulnerability

Please **do not** open a public issue. Instead, use GitHub's private reporting: **Security → Report a vulnerability** on https://github.com/apibear/apibear, or email support@apibear.com.

Include the version (`apibear --version`), steps to reproduce, and impact. We aim to acknowledge reports within 3 business days.

## Supported versions

Only the latest published release receives fixes.
